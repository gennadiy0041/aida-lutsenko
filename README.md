# Aida Lutsenko — a film in four chapters

Personal site of Aida Lutsenko, built as a short film: opening titles, four chapters, end credits.

- Stack: Astro, Tailwind CSS, GSAP, Lenis. Static output.
- Images: AVIF / WebP generated at build time from graded masters in `src/assets`.
- Deploy: Railway, auto-deploy on push to `main`.

## Develop

```sh
npm install
npm run dev
npm run build
```

Requires Node.js 22.23.4 or newer.
